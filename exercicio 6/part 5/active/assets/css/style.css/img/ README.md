# 🛒 MercadoTech - E-commerce & Site Institucional

Projeto final desenvolvido para venda simulada de produtos de tecnologia e apresentação institucional da empresa.

## 🔗 Links do Projeto
* **Repositório:** [https://github.com/lucassilva/mercadotech](https://github.com/lucassilva/mercadotech)
* **Site Publicado:** [https://lucassilva.github.io/mercadotech/](https://lucassilva.github.io/mercadotech/)

## 📄 Páginas do Site
- **Home:** Apresentação da marca MercadoTech, banners promocionais e produtos em destaque.
- **Produtos:** Catálogo completo com notebooks, smartphones, acessórios e periféricos gamer.
- **Institucional:** História da MercadoTech, nossa missão, visão, valores e compromisso com a tecnologia.
- **Contato:** Formulário de atendimento ao cliente, mapa fictício e canais de suporte.
- **Carrinho Simulado:** Visualização dos itens selecionados, resumo de valores e simulação de checkout.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3 (Bootstrap 5 + CSS Externo em `assets/css/style.css`)
